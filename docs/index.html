Veliq

Local-first screen & photo translator — macOS, iOS and Android

Veliq is a free, open-source utility that reads the text on your screen. Drag a region of the display — or pick / take a photo — and Veliq extracts the text on your device (Apple Vision on macOS and iOS; ML Kit and Tesseract on Android) and shows the Persian translation. Images never leave the machine: only the recognised text goes to the translation provider, and the default one — Google Translate — needs no API key.

Download the Android APK Source code on GitHub

Highlights

  • On-device OCR — Apple Vision (macOS / iOS); ML Kit + Tesseract on Android, including Persian, Arabic and Russian; the image stays in memory.
  • No API key needed — the default provider is Google Translate's free endpoint. Optionally use Gemini with your own key (stored in the OS keychain / keystore) or Apple's on-device engine.
  • Region capture on macOS — a ScreenCaptureKit overlay lets you select any part of the screen.
  • Photo & camera input on mobile — no photo-library permission required (Photo Picker / PHPicker).
  • Persian first — a right-to-left, justified result view with copy actions and a local, deletable history.
  • No accounts, no ads, no tracking, no backend.

Build from source

git clone https://github.com/moradzadeh67/veliq.git
cd veliq
flutter pub get
flutter run -d macos

Requirements: Flutter 3.47.2, Dart 3.13.2, macOS 14.6+, Xcode for the Apple targets, and the Android SDK 24+ for Android. Full instructions live in the README.

Privacy in one line

Screenshots and photos are processed in RAM and discarded; only the extracted text is transmitted, over HTTPS, to the provider you configure. See docs/PRIVACY.md.
